# Wiring — ESP32 → Epson LX-810L (Centronics parallel)

> ⚠️ **First things first:** the printer runs off mains, not off the ESP32.
> Never connect/disconnect wires with anything powered. The ESP32 is **not
> 5 V tolerant** — that's why the return lines from the printer go through a
> resistive divider.

## Overview

```
                 +3V3 ─┐                          +5V (the "5V"/"VIN" pin of the ESP32, from USB)
                       │                           │
  ESP32            ┌───┴────────────┐          ┌───┴──────┐
  ┌───────┐        │   TXS0108E     │          │ pull-ups │
  │ GPIO  │ D0..D7 │ A1..A8  B1..B8 │ D0..D7   │  10k x2  │
  │ 13..21├────────┤(3V3 side)(5V)  ├──────────┤ /STROBE  ├───► DB25 ──cable──► LX-810L
  │       │        │  OE ◄── GPIO4  │          │ /INIT    │      (male)        (Centronics 36)
  │ 19,18 ├────────────────────────────────────┤          │
  │       │        └────────────────┘          └──────────┘
  │ 34,35 │◄──── 1k8/3k3 divider ◄──────────────────────────── BUSY, PE
  │ 39,36 │◄──── 1k8/3k3 divider ◄──────────────────────────── /ERROR, SELECT
  └───┬───┘
      │
     GND ─────────── common: ESP32 GND + TXS0108E GND + divider bottoms + DB25 18..25
```

The 5 V come from the DevKit's **`5V`** (or `VIN`) pin, which mirrors USB
5 V. Since the ESP32 is always plugged into the PC, that's enough. **GND must
be common** between ESP32 and printer (the cable's GND wires already do this).

## DB25 connector (PC side) — this is where your cable plugs in

Your cable is DB25-male ↔ Centronics-36. Solder a **male DB25** to your
proto/perfboard and wire it per the table. The cable plugs into that DB25,
the other end goes to the printer.

| DB25 | Signal     | Direction      | Connects to                          | How |
|-----:|------------|----------------|--------------------------------------|-----|
| 1    | /STROBE    | ESP32 → printer| GPIO **19**                          | direct + 10k pull-up to +5V |
| 2    | D0         | ESP32 → printer| TXS0108E **B1** (A1 ← GPIO13)         | via level shifter |
| 3    | D1         | ESP32 → printer| TXS0108E **B2** (A2 ← GPIO14)         | via level shifter |
| 4    | D2         | ESP32 → printer| TXS0108E **B3** (A3 ← GPIO27)         | via level shifter |
| 5    | D3         | ESP32 → printer| TXS0108E **B4** (A4 ← GPIO26)         | via level shifter |
| 6    | D4         | ESP32 → printer| TXS0108E **B5** (A5 ← GPIO25)         | via level shifter |
| 7    | D5         | ESP32 → printer| TXS0108E **B6** (A6 ← GPIO23)         | via level shifter |
| 8    | D6         | ESP32 → printer| TXS0108E **B7** (A7 ← GPIO22)         | via level shifter |
| 9    | D7         | ESP32 → printer| TXS0108E **B8** (A8 ← GPIO21)         | via level shifter |
| 10   | /ACK       | printer → ESP32| *(unused)* — optional                | 1k8/3k3 divider to a free GPIO |
| 11   | BUSY       | printer → ESP32| GPIO **34**                          | **1k8/3k3 divider** |
| 12   | PE         | printer → ESP32| GPIO **35**                          | **1k8/3k3 divider** |
| 13   | SELECT     | printer → ESP32| GPIO **36** (SVP)                    | **1k8/3k3 divider** |
| 14   | /AUTOFEED  | ESP32 → printer| **+5V**                              | fixed jumper (disables auto-LF) |
| 15   | /ERROR     | printer → ESP32| GPIO **39** (SVN)                    | **1k8/3k3 divider** |
| 16   | /INIT      | ESP32 → printer| GPIO **18**                          | direct + 10k pull-up to +5V |
| 17   | /SELECT-IN | ESP32 → printer| **GND**                             | fixed jumper (keeps it selected) |
| 18–25| GND        | —              | **common GND**                      | all tied together |

> Centronics-36 (printer side), if you prefer to solder straight to it:
> 1=/STROBE · 2–9=D0–D7 · 10=/ACK · 11=BUSY · 12=PE · 13=SELECT · 14=/AUTOFEED
> · 16=logic GND · 31=/INIT · 32=/ERROR · 19–30=GND · 36=/SELECT-IN.

## TXS0108E (the 8-channel module you already have)

| TXS0108E pin | Connects to |
|--------------|-------------|
| VCCA         | ESP32 **3V3** |
| VCCB         | **+5V** (ESP32 `5V`/`VIN` pin) |
| GND          | common GND |
| OE           | GPIO **4** + **10k pull-down to GND** |
| A1..A8       | GPIO 13, 14, 27, 26, 25, 23, 22, 21 |
| B1..B8       | DB25 pins 2, 3, 4, 5, 6, 7, 8, 9 |

- **VCCA must be ≤ VCCB.** Here 3.3 V on A, 5 V on B. Correct.
- `OE` with a pull-down keeps the shifter **high-impedance** until the
  firmware calls `printer.begin()` — without it the pins could squirt data
  into the printer during boot.
- The TXS0108E is *auto-direction*. For D0..D7 (always ESP32 → printer) it
  works, but it's the weakest link. **If prints come out garbled**, replace
  the 8 data bits with a **74HCT541** or **74HCT245** (3.3 V-compatible
  input, real 5 V push-pull output) — bulletproof for a one-way bus.

## Resistive divider (every signal coming from the printer)

BUSY, PE, /ERROR and SELECT leave the printer at **5 V**. Each one:

```
  DB25 (BUSY / PE / ERROR / SELECT)
        │
      [ 1k8 ]        (top R)
        │
        ├───────────►  ESP32 GPIO  (34 / 35 / 39 / 36)
        │
      [ 3k3 ]        (bottom R)
        │
       GND  (common)
```

`Vgpio = 5 V × 3k3 / (1k8 + 3k3) ≈ 3.24 V` → a safe high, never above 3.3 V.

- Alternative acceptable values: 10k/15k (loads the printer output less).
- Four dividers → **4× 1k8 + 4× 3k3**.
- With the **printer off**, these pins are pulled to GND by the bottom
  resistor → the firmware reads `SELECT = low` (offline) and `/ERROR = low`
  (fault) and **won't try to print**. That's the intended behaviour.

## /STROBE and /INIT (ESP32 outputs straight to the DB25)

```
  GPIO19 ──┬────────────►  DB25 pin 1  (/STROBE)
           │
         [ 10k ]
           │
          +5V
```
(same for **GPIO18 → DB25 pin 16 (/INIT)**, with another 10k to +5V)

- 3.3 V is already a valid logic high for the printer's TTL input, so it
  doesn't need the shifter.
- The **10k pull-up to +5V** keeps the line **idle (high)** while the ESP32
  resets, avoiding an accidental strobe/reset pulse.
- Optional (extra short protection): a **1k in series** between GPIO and DB25.

## Why this pin map

It avoids the pins that cause grief on the ESP32 classic:

| Pins | Reason | In this project |
|------|--------|-----------------|
| 6–11 | wired to the SPI flash | never used |
| 0, 2, 5, 12, 15 | *strapping* (boot level matters) | only GPIO2 (LED), configured after boot |
| 16, 17 | PSRAM on WROVER modules | not used |
| 34–39 | **input only**, no internal pull | used on purpose for status (level comes from the divider) |
| 1, 3 | UART0 = USB (the "bridge") | reserved for Serial |

Suggested power-up order: connect GND first, then power the ESP32 (USB),
then the printer last. Check all wiring with the printer **off** before the
first test.
